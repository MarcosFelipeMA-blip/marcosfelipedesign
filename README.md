# Marcos Felipe Design

Site da Marcos Felipe Design: sites para negócios locais.

No ar em: https://marcosfelipema-blip.github.io/marcosfelipedesign/

## Como editar

Tudo fica em `index.html` (textos, cores e o número do WhatsApp).

- **Número do WhatsApp:** procure `var WHATSAPP` no fim do arquivo.
- **Preço:** procure `R$ 1.200`.
- **Cores:** as variáveis no topo do `<style>` (`--navy`, `--accent`).

Depois de salvar e enviar para o GitHub, o site se atualiza sozinho em
1 ou 2 minutos.
